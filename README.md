# 🚗 Auto-Hub-garage

Auto-Hub Garage — A modern automotive automation services website built with React, Tailwind CSS, and Canva.

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- JavaScript
- HTML5

## ✨ Features

- 🚗 Explore cars and automotive information
- 🔧 Garage and automotive services
- 📋 Service information
- 🎨 Modern and clean user interface
- 📱 Fully responsive design
- ⚡ Fast and interactive React.js interface
- 🧭 Easy navigation
- 📱 Mobile-friendly layout
